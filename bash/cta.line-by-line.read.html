read — bash cheat sheet

Read input from stdin, one line at a time

Basic syntax
# read one line into a variable
read variable_name

# split a line into two variables on whitespace
read first last

# show a prompt before reading
read -p "Enter name: " name
Common patterns
Read a single line
read line
echo "$line"
Read multiple lines manually
read line1
read line2
read line3
echo "$line1"
echo "$line2"
echo "$line3"
Read all lines — while loop
while read line; do
  echo "$line"
done

Works for any number of lines without changes

Read into an array
mapfile -t lines \
  < /dev/stdin

echo "${lines[0]}"
echo "${lines[1]}"
How input arrives
From a pipe
echo "hello" | ./test.sh

# inside test.sh:
read line  # gets "hello"
From a file
while read line; do
  echo "$line"
done < passwords.txt
Pipe + args together
echo "secret" \
  | ./test.sh arg1

# inside test.sh:
read secret_val # pipe
arg1="$1"       # args
10 lines from a pipe
cat passwords.txt \
  | ./test.sh

# each line arrives
# one at a time
Useful flags
FlagDescription
-p "text"Show a prompt before reading
-sSilent mode — hides input (good for passwords)
-rRaw mode — don't treat backslash as escape. Use this by default.
-n NStop after N characters — don't wait for Enter
-t NTimeout after N seconds
-a arrRead words into an array instead of a string

Breaks if input has 9 or 11 lines

Stage 2 — while loop
#!/bin/bash
while read -r line; do
  echo "$line"
done

Works for any number of lines. Nothing to change. This is the refactor.

How read works — step by step
stdin opens
│
▼
read waits for a line
│
├── line arrives → stored in variable → your code runs
│
└── no more input → read returns false → loop ends
Gotchas
⚠ read only gets one line — pipe 10 lines in and call read once, you get the first line only. The rest are dropped.
⚠ Missing quotes — echo $line collapses spaces and breaks on special characters. Always use echo "$line".
⚠ Reusing the same variable — calling read line 10 times overwrites the value each time. Use different names or use a loop.
✓ Use while read -r line as your default. The -r flag prevents backslashes in input from being swallowed.
✓ Use done < file instead of cat file | while read — the pipe version runs the loop in a subshell and variables set inside the loop won't survive after done.
